# Proyecto Hospitalario — Módulo Pacientes (Glendi Campos)

Este repositorio organiza, semana a semana, el trabajo realizado por **Glendi Patricia Campos Orellana (`Glendi20`)** en el **Módulo 03 — Paciente local, búsqueda y vínculo con MPI CENTRAL**, dentro del proyecto de curso "Sistema Hospitalario Integral" (repositorio original: `shi-asii-03-pacientes`, rama `feature/asii-03-pacientes-glendi20`).

Cada carpeta `Semana N` contiene la documentación y el código **nuevo o modificado esa semana**, tal como quedó al cierre de la entrega correspondiente.
